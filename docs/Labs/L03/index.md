**3 Infills**
Grid Infill- is a useful 3D general infill for 3D parts. The crossing lines provide strength in the horizontal layers and give good support for to the top layers of the print.

Wiggle Infill- the wiggle infill uses a wavy pattern inside the part. It is useful when creating a part that needs to flex and it uses less material because it is not very dense.

**Research**

The infill percentage can affect the strength, weight, and print time of the part. A higher infill puts more material inside the part, and it makes it less prone to crush or bend. 

Different infill patterns can change how the forces are distributed throughout the part. Different patterns can provide support on certain areas. Like for the triangle infill it is strong because the triangles can resist deformation. 

Using different wall thicknesses can control the strength and durability of the outer layer of the part. Thick walls can make the part stronger and can handle heavier loads or impacts. The downfall of having thicker walls is that it increases the print time and it uses more material.
